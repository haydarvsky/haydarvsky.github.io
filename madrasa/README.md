# مدرستي — haydarvsky.github.io/madrasa/

أداةُ المعلّم: التحضيرات (PDF بالصفِّ والفصلِ الدراسي) + متابعةُ المتعلّمين (غياب/مشاركة/خروج/سلوك/ملاحظات) + لوحاتُ قياسٍ تُصدَّرُ PDF + الجدولُ الأسبوعي.

- `index.html` تطبيقُ صفحةٍ واحدة بتوجيهِ هاش: `#/` اليوم · `#/prep/<10|11|12>/<1|2>` · `#/classes` · `#/class/<id>` (يومي) · `#/class/<id>/students` · `#/class/<id>/report` · `#/student/<cls>/<sid>` · `#/schedule` · `#/settings`
- `js/fb.js` Auth + Firestore عبر REST (مشروع vak-quiz-96d5f). `?demo=1` وضعٌ محليٌّ ببذرةٍ تجريبية.
- `js/charts.js` أعمدةٌ مكدَّسةٌ أسبوعية + تقويم. `js/app.js` الواجهات.
- التحضيرات: `data/prep.json` + `prep/<صف>/<فصل>/<ملف>.pdf` — تُرفَعُ من الصفحةِ برمزِ GitHub (`hv_token`) عبر `/admin/js/gh-api.js`، أو تُوضَعُ يدوياً وتُضافُ إلى prep.json.
- فايرستور: `sc_meta/settings` (الفصولُ الدراسية، الجدول، الحصص) · `sc_classes/{id}` (الفصلُ وطلابُه) · `sc_days/{cls}_{YYYY-MM-DD}` (تسجيلاتُ يومٍ لفصل). القواعدُ في `قواعد-فايرستور.txt`.

## الإصدار ٢ (٥ سبتمبر ٢٠٢٦)
- **بلا إنترنت**: طابورُ كتابةٍ في `localStorage` (`sc_queue_v1`) يُفرَّغُ عند عودةِ الشبكة؛ نسخةُ أيامِ كلِّ فصلٍ في `sc_days_<cls>`؛ شريطٌ برتقاليٌّ يعرضُ الحالة.
- **PWA**: `manifest.webmanifest` + `sw.js` (الهيكلُ من الذاكرة، والبياناتُ من الشبكةِ أوّلاً) + `icons/`.
- **نسخٌ احتياطي**: JSON كامل (يُستعاد) + CSV لكلِّ التسجيلات؛ CSV لكلِّ تقريرِ فصل.
- **تحديدُ الغائبين**: وضعٌ سريع يبدّلُ الغيابَ بنقرةٍ + «تمّ التحضير» (`taken:true` على وثيقةِ اليوم).
- **بحثٌ وترتيب** (ترتيبي/أبجدي/رقمُ الجلوس) وسحبٌ للترتيب وحقلُ `no` لكلِّ متعلّم.
- **أرشفة**: فصلٌ مفرد أو العامُ كلُّه (`archived, archivedAt, year`)، والمؤرشفُ يُعرَضُ للقراءة.
- **تصنيفات** `settings.cats.{star,bad}` تُختارُ عند التسجيل (`ev.cat`) وتُرسَمُ في التقارير.
- **درجةُ السلوك** بأوزانِ `settings.weights` + تنبيهاتٌ عند `absAlert/badAlert`.
- **رسالةُ وليِّ الأمر**: نصٌّ قابلٌ للنسخ/واتساب + PDF صفحةٍ واحدة (`body.brief`).
- **مقارنةُ الفصول** `#/overview`. **وسومُ التحضيرات** (وحدة/درس/أسبوع/تاريخُ الحصّة) وبحث، وتحضيرُ اليومِ في الرئيسة.
- **سجلُّ التعديلات** `sc_log/log_YYYY-MM` (`#/log`). **مشرفٌ قارئ**: `sc_meta/access.viewers` + قواعدُ `scViewer()`.

## السبّورةُ الناطقة — `sabbura.html` (١٤ أكتوبر ٢٠٢٦)
لوحةُ عرضٍ تسمعُ شرحَ المعلّم (Web Speech API، `ar-SA` افتراضياً) وترتّبُ كلامَه على السبّورة إنفوجرافيكاً متحرّكاً، صفحةٌ واحدةٌ مستقلّةٌ بلا دخول (الرابطُ في شريطِ الأقسام وفي «اليوم»).
- **المحرّكُ الفوري** (`apply()`): قواعدُ عربيّةٌ على الجملةِ المنطوقة ← ١٤ شكلاً: عنوان، تعريف بقوس، قائمة بخاناتٍ تملأُ نفسَها («للكلمة ثلاثة أقسام»)، خطوات، دورة، أرقام (حلقةُ نسبةٍ/أعمدة)، مقارنة بعمودين، سببٌ ونتيجة، خطٌّ زمني، سؤالٌ وجوابُه، اقتباس، تنبيه/خلاصة، فكرة، كلمةٌ مفتاحية، وبطاقاتُ «مثال». الأعدادُ المنطوقةُ كلماتٍ تتحوّلُ أرقاماً (مع حمايةِ «الحادي عشر» و«ألّف» و«آلاف»).
- **المحرّكُ الذكي** (اختياري): Claude عبر `fetch` مباشرةً من المتصفّح بمفتاحِ المعلّم (localStorage)، مخرجاتٌ منظّمةٌ `json_schema` بإجراء new/update/ignore؛ عند أيِّ خطأٍ يعودُ إلى المحرّكِ الفوري.
- **أدواتُ الشرح**: قلمٌ (أسود/أبيض/أزرق/أحمر × ٣ سماكات، الرسمُ محفوظٌ لكلِّ مشهدٍ بوحدةِ `--U`)، ليزرٌ بأثرٍ يتلاشى، ممحاة، تراجع، سبّورةٌ خضراء/ورقةٌ بيضاء، ملءُ الشاشة، طباعةُ المشاهدِ PDF بمقاس ١٦٠٠×٩٠٠.
- الحفظ: `sabbura_v1` (المشاهدُ والرسمُ والنص) و`sabbura_set` (الإعدادات) و`sabbura_stash` (سبّورةُ المعلّمِ أثناءَ الدرسِ التجريبي).

## حقيبةُ الدرس (١٥ أكتوبر ٢٠٢٦)
بطاقاتٌ دقيقةٌ من الكتابِ المدرسيّ لكلِّ درس تستدعيها «السبّورةُ الناطقة» حين يتكلّمُ المعلّم، فتظهرُ كما في الكتاب (أبياتٌ بتشكيلِها، كلماتُ المعجم، جداول، قواعد، أمثلةٌ وإعرابُها، أسئلةُ التدريب بأجوبتِها، صورٌ مقصوصة، وصفحاتُ الكتاب).
- `data/packs/<lessonId>.json`: `{id,title,book,pages,printed,summary,cards:[{id,kind,page,keys,…}]}` — الأنواع: intro, verse{verses:[{n,a,b}]}, word, definition, rule, list, steps, table{head,rows}, compare, example{text,note}, question{title,text(الجواب),items}, idea, image{crop}.
- `packs/img/<book>-<PDFpage>.jpg` صفحاتُ الدروس (عرض ١١٠٠) و`packs/img/crop/<pack>-<card>.jpg` صورُ بطاقاتِ image.
- الفهرس `data/lessons/index.json`: لكلِّ درسٍ له حقيبة `pack:true` و`book` (g10-arabi | g10-nahw | g10-balagha) و`bp:[من، إلى]` صفحاتُ PDF و`bpr` المطبوعة؛ فتظهرُ في التحضيرات أزرارُ «حقيبةُ الدرس» (`sabbura.html?lesson=<id>`) و«الكتاب ص…» (`book.html?id=…&p=…`).
- أوّلُ الحقائب: موضوعُ «المجدُ لمن يُغامر» كاملاً (١٢ درساً، ٤١٩ بطاقة).
